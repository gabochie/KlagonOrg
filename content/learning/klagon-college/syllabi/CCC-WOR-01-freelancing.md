# CCC-WOR-01 — Freelancing & Remote Work Foundations

- Home: CCC / Future · Level L1 · 3 weeks · 5 lessons · Elective · pilot
- Prerequisites: CCC-CAR-01. Builds on CV/pitch.
- Why: monetisation bridge from learning to income (local + remote).

## Outcomes
1. Position one sellable service with clear scope and price.
2. Build a one-page portfolio with 2–3 proof pieces (course projects count).
3. Write proposals that answer brief, process, price, and timeline.
4. Deliver professionally: contract basics, communication, MoMo/bank payment, review.

## Skills
freelancing, remote-work, professional-identity

## Lessons
1. **Pick Your Service** — skills inventory, niche, scope in/out, starter price (cedis + USD). Do: one-service sheet. Evidence: sheet.
2. **One-Page Portfolio** — headline, 3 proofs (use SOD-VIS-01/SOA-PHO-01/SOT-AI-01 artifacts), testimonials, contact. Do: publish page/doc. Evidence: link.
3. **Proposals That Win** — read the brief, diagnose, propose steps, price options, timeline, next step. Do: 3 tailored proposals (real or realistic briefs). Evidence: proposals.
4. **Delivery & Client Comms** — kickoff questions, updates, revisions, boundaries, async tools (WhatsApp business, email, shared docs). Do: delivery checklist + message templates. Evidence: pack.
5. **Money & Reputation** — quotes, deposits, MoMo/bank, simple agreement, reviews, taxes note (get local advice). Do: invoice + agreement template + review request. Evidence: templates.

## Final project
Portfolio page + 3 proposals sent (or reviewed by mentor) + delivery/money pack.

## Assessment
Pass = portfolio live + 3 proposals + pack. Passport: `freelancing-foundations — Demonstrated`. Links to Opportunities (jobs/projects/mentors).
