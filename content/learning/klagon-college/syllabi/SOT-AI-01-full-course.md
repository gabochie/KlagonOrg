## Lesson 1 — Pick 3 Tasks Worth Automating (20 min)
**Goal:** leave with a ranked list of 3 tasks + time baseline.
1. List every repeat task you did last week (15-min brain dump; include MoMo reconciliation, follow-ups, quotes, stock counts, reports).
2. Score each 1–5 on Frequency + Pain + Error-cost. Total = priority.
3. Time your top 5 with your phone stopwatch for 2 days. Write the baseline ("Quotations: 45 min/day").
4. Ghana filter: does it need data to run? Does it touch customer money? If yes, it needs a human checkpoint — mark it.
5. Commit: "I will automate ___, ___, ___ and save ___ hrs/week."
**Evidence:** photo/screenshot of score sheet + baseline times.

## Lesson 2 — Prompt Like a Supervisor (20 min)
**Goal:** 3 reusable prompts that work twice in a row.
- Formula: Role ("You are my shop assistant") → Task → Constraints (price list, tone, length) → Format (table, message, sheet row).
- Templates: quotation reply, polite follow-up, daily sales summary, CV cover note.
- Safety: never paste full MoMo PINs/passwords; verify numbers; re-run once; if the two runs disagree, keep the human version.
- Hallucination drill: ask for a fake Tema regulation — watch it invent; learn the "verify before sending" habit.
**Evidence:** paste your 3 prompts + both outputs.

## Lesson 3 — Build the Blueprint (30 min + build day)
**Goal:** all 3 automations sketched end-to-end.
- Stack (all free): phone notes → free AI → Google Docs/Sheets → WhatsApp Business.
- Example A (shop): price list in Sheets + prompt → quotation in 60 seconds → WhatsApp send.
- Example B (freelancer): brief → proposal draft → checklist → follow-up reminder in calendar.
- Example C (jobseeker): 1 master CV → tailored version per advert in 10 min + tracking sheet.
- Draw each as: Trigger → AI step → Human check → Send/File. Screenshot each step.
**Evidence:** blueprint doc (3 flows + screenshots).

## Lesson 4 — Go Live + Measure (7-day run)
**Goal:** proof, not promises.
- Run all 3 on real work for 7 days. Log daily: time taken, errors, money/customers touched.
- Fix loop: what broke → smallest fix → re-run. Post one fix in the WhatsApp group.
- Scam/privacy check: app permissions audit, MoMo-fraud red flags, customer-data rule (no customer lists into random tools).
**Evidence:** 7-day log + before/after hours.

## Lesson 5 — Showcase + Certificate (30 min)
**Goal:** asset you can send to a boss or client.
1. Write the 1-page blueprint (problem → 3 flows → hours saved → screenshots).
2. Record a 2-min phone demo (screen + voice; no face needed).
3. Submit both. Review in 48h. Pass = certificate + `ai-literacy — Demonstrated` badge.
**Evidence:** blueprint PDF + demo link.
