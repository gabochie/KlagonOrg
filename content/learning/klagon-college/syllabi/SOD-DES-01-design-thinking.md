# SOD-DES-01 — Design Thinking: Solve a Local Problem

- School: SOD / Foundations · Level L1 · 4 weeks · 6 lessons · Core · pilot
- Prerequisites: CCC-COM-01 recommended. Paper + phone prototyping only.
- Why: single gateway to all Design; every learner leaves with a tested prototype.

## Outcomes
1. Observe and interview to define a real local problem.
2. Map stakeholders and reframe the problem (How Might We).
3. Ideate divergently, converge on one testable concept.
4. Prototype with paper/phone and run 3 user tests.

## Skills
design-thinking, systems-thinking, prototyping, research

## Lessons
1. **See Like a Designer** — observation, photo safari, assumption log. Do: 10-observation log in your community. Evidence: log.
2. **Listen: Interviews** — 5-whys, consent, note-taking on phone. Do: 3 five-minute interviews. Evidence: notes + quotes.
3. **Define: From Mess to HMW** — affinity map, stakeholder map, problem statement. Do: one HMW + stakeholder map. Evidence: one-pager.
4. **Ideate** — Crazy-8s, worst-idea, dot-vote. Do: 16 ideas → top 1 with rationale. Evidence: idea sheet.
5. **Prototype Fast** — paper UI / storyboard / role-play; free phone tools optional. Do: build v1 prototype. Evidence: photos.
6. **Test & Iterate** — 3 tests, feedback grid (liked/wished/questions/ideas), v2 decision. Do: test log + next-step plan. Evidence: test table.

## Final project
Prototype + test report: problem, HMW, prototype photos, 3 test results, v2 recommendation. Ghana lens: market, school, transport, waste, water, or local business case.

## Assessment
Rubric: problem evidence (30), prototype clarity (30), test rigour (25), presentation (15). Pass ≥60. Passport: `design-thinking — Demonstrated` with report as evidence. Portfolio-ready.
