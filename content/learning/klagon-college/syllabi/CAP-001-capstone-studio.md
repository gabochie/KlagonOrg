# CAP-001 — Community / Venture Capstone Studio

- Type: shared capstone · Level L1 · 4 weeks · Capstone · pilot
- Prerequisites: enrolment in P1 or P2 (or P3 portfolio track); ≥2 constituent courses complete.
- Why: single reviewer + evidence pipeline so projects become Passport proof, not dead PDFs.

## Tracks
- **Venture track (P1):** micro-business dossier — offer, validation, pricing, sales log, P&L.
- **Community track (P2):** project dossier — need, plan, execution log, measurable outcome, handover.
- **Portfolio track (P3):** 3-piece portfolio + artist/designer statement (reviewed here).

## Weeks
1. **Scope & Evidence Plan** — problem/need, outcome metric, evidence list, risks. Output: one-page charter.
2. **Build / Execute** — weekly log, mentor check-in, blockers + pivots. Output: log + artifacts.
3. **Measure & Document** — before/after, numbers, testimonials, finances where relevant. Output: draft dossier.
4. **Showcase & Handover** — 5-min demo/talk, reviewer feedback, next steps, consent for public Passport items. Output: final dossier + demo.

## Assessment
Rubric: real-world execution (35), evidence quality (25), measurable outcome (20), showcase clarity (20). Pass ≥60 + mentor/reviewer sign-off.
Public Passport items require explicit learner consent; private logs stay private.

## Outputs to Passport
- P1: `venture-launched — Demonstrated` + revenue/validation evidence.
- P2: `community-project — Demonstrated` + outcome report.
- P3: `portfolio — Demonstrated` + 3 pieces.
