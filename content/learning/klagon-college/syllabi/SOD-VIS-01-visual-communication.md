# SOD-VIS-01 — Visual Communication for Beginners

- School: SOD / Graphic · Level L1 · 4 weeks · 6 lessons · Elective · pilot
- Prerequisites: none. Free mobile tools (e.g. Canva, Snapseed, phone camera).
- Why: type/layout/brand basics feeding portfolios, businesses, community comms.

## Outcomes
1. Apply hierarchy, alignment, contrast, spacing to any layout.
2. Set readable type (pairing, size, line length) for print and phone screens.
3. Build a mini brand kit (colours, fonts, logo use, templates).
4. Export correct files for print, WhatsApp, and social.

## Skills
visual-literacy, typography, branding

## Lessons
1. **Seeing Layout** — hierarchy, grid, whitespace; teardowns of posters/signs. Do: annotate 3 local designs (good/bad). Evidence: teardown notes.
2. **Type That Reads** — one display + one text font, sizes, contrast. Do: reset a messy flyer in two sizes (print + status). Evidence: before/after.
3. **Colour & Images** — 3-colour palette, contrast ratios, free-licensed images, consent. Do: palette + image set for a real client/community. Evidence: style tile.
4. **Mini Brand Kit** — logo use, dos/don'ts, 2 templates. Do: one-page kit for your project or business. Evidence: kit PDF/image.
5. **Poster + Social Set** — one message, three formats. Do: A4 poster + square + status-size from the kit. Evidence: 3 exports.
6. **Preflight & Handoff** — resolution, bleed/safe area, file naming, printer/vendor brief. Do: export pack + one-paragraph vendor note. Evidence: file pack.

## Final project
Mini brand kit + poster set (3 formats) for a real community group, business, or P1/P2 project.

## Assessment
Rubric: readability (30), consistency to kit (30), fitness for audience/format (25), files correct (15). Pass ≥60. Passport: `visual-communication — Demonstrated`.
