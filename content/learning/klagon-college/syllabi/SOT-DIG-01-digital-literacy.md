# SOT-DIG-01 — Digital Literacy: Start Without a Laptop

- School: SOT / Digital Foundations · Level L0 · 3 weeks · 6 lessons · Core · pilot
- Prerequisites: none. Phone-only. Low-bandwidth friendly.
- Why: on-ramp for mobile-only learners; prerequisite for CCC-AI-01, SOT-AI-01.

## Outcomes
1. Manage files, accounts and passwords safely on a phone.
2. Use cloud storage, email, and mobile productivity (docs, sheets, calendar).
3. Spot scams, protect data, control privacy and sharing.
4. Set up a personal productivity system that works offline.

## Skills
digital-literacy, digital-safety, digital-productivity

## Lessons
1. **Your Phone Is a Computer** — OS basics, storage, data costs, offline mode. Do: audit storage/data, enable screen lock + backup. Evidence: screenshot checklist.
2. **Accounts & Passwords** — email, recovery, passphrases, 2FA via SMS/authenticator. Do: secure 3 accounts, write recovery sheet (paper). Evidence: security checklist (no passwords submitted).
3. **Files & Cloud** — Drive/equivalent: folders, naming, share links, offline files. Do: build `Klagon/` folder tree, share one file view-only. Evidence: link + structure list.
4. **Docs, Sheets & Calendar on Mobile** — create, voice-type, basic formulas, shared calendar. Do: budget sheet + study calendar. Evidence: shared sheet.
5. **Internet Safety & Scams (Ghana lens)** — MoMo fraud, phishing, fake jobs/scholarships, permissions. Do: analyse 3 real scam examples, set app permissions. Evidence: scam-spotting quiz + reflection.
6. **My Productivity Setup** — capture → organise → review; offline-first routine. Do: publish one-page setup + weekly review habit. Evidence: setup doc.

## Final project
Personal digital safety + productivity setup: folder tree, secured accounts checklist, budget sheet, calendar, scam-response note.

## Assessment
Pass = all 6 checklists + project submitted + quiz ≥70%. Passport: `digital-literacy — Demonstrated` with setup doc as evidence.
